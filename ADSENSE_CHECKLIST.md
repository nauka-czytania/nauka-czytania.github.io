# NaukaCzytania 2.0 – checklista przed ponownym zgłoszeniem do AdSense

## Zawartość serwisu

- [x] Główne narzędzie do podziału własnego tekstu.
- [x] Osobna ścieżka: litery → sylaby → wyrazy → zdania → czytanki.
- [x] Interaktywne ćwiczenia bez kont użytkowników.
- [x] 12 autorskich czytanek w trzech poziomach trudności.
- [x] Każda czytanka ma pytania sprawdzające rozumienie tekstu.
- [x] Każdą czytankę można przenieść do czytnika i podzielić na sylaby.
- [x] Poradnik, opis projektu, polityka prywatności i strona kontaktowa.
- [x] ads.txt z identyfikatorem wydawcy.

## Przed wysłaniem do ponownej oceny

- [ ] Wgraj CAŁĄ zawartość paczki do katalogu głównego GitHub Pages.
- [ ] Sprawdź ręcznie wszystkie pozycje głównej nawigacji.
- [ ] Sprawdź, czy `/ads.txt` otwiera się jako zwykły tekst.
- [ ] Oznacz całą witrynę jako skierowaną do dzieci w narzędziach Google/Search Console.
- [ ] Przy ręcznych jednostkach reklamowych stosuj aktualny TFAT CHILD (`data-tag-for-age-treatment="1"`).
- [ ] Skonfiguruj w AdSense sekcję Prywatność i wiadomości / właściwe rozwiązanie CMP dla obsługiwanych regionów.
- [ ] Dodaj witrynę do Google Search Console i poproś o indeksację strony głównej oraz najważniejszych podstron.
- [ ] Odczekaj, aż nowe strony zostaną zaindeksowane; nie wysyłaj do ponownej oceny natychmiast po uploadzie.
- [ ] Przetestuj witrynę na telefonie i komputerze.

## Dlaczego ta wersja jest większa

Google przy odrzuceniu z powodu niewystarczającej/mało wartościowej treści zwraca uwagę m.in. na wystarczającą ilość tekstu w pełnych zdaniach i akapitach oraz na to, czy witryna jest kompletna. Ta aktualizacja nie dodaje pustych stron „pod SEO”; rozbudowuje serwis o rzeczywiste materiały edukacyjne, które korzystają z funkcji czytnika.
